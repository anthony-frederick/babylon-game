# 3D Asteroids

This is a remake of the original **Asteroids**, but in 3D. The goal is to destroy all of the asteroids without dying.

Asteroids that collide with you deal damage. If your health reaches zero, the game ends.

## Controls

| Action | Control |
|---|---|
| Look around | Mouse |
| Fire | Left Click |
| Restart after game over | `R` |
| Enter inspection mode | `0` |
